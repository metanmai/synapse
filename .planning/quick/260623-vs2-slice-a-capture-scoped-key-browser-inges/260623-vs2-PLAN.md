# Slice A: capture-scoped key + browser ingest endpoint (backend)

Foundation for the self-sufficient extension (user chose: OAuth device flow + capture-only scoped token + keep daemon fallback). This slice is the security-critical core — built, tested, adversarially checked, then **held for review before any push** (a push auto-deploys to prod).

## Tasks

1. **Migration 031** — `api_keys.scope text NOT NULL DEFAULT 'full'` + CHECK in ('full','capture'). Idempotent (`ADD COLUMN IF NOT EXISTS`). Existing keys unchanged.
2. **Scrub → `@synapse/shared`** — move `scrubSecretValues` to `packages/shared/src/redact.ts` (one source of truth for the security scrub); mcp's `redact.ts` re-exports it (daemon import path unchanged); backend imports it.
3. **Feature-detected scope read** — `findUserByApiKeyHash` selects `*, users(*)` so `scope` is read only if the column exists; `undefined` (pre-migration prod) → defaults to `'full'`. Avoids the new-column-before-migrate 500 trap.
4. **Fail-closed enforcement in `authMiddleware`** — a `'capture'`-scoped key is `403`'d on EVERY path except the one allowlisted `POST /api/capture/browser`. Centralized, so future routes are auto-protected. JWT/session = `'full'`.
5. **`POST /api/capture/browser`** — Bearer-auth'd; allowlist `{host ∈ CAPTURE_HOSTS, messages:[{role,content,ts}]}`; scrub each content; persist via `findOrCreateProjectByGit` (per-host project, MVP) + `createConversation` + `appendMessages`. Global rate-limit already applies.
6. **CORS** — allow `chrome-extension://` origins (Bearer auth, no cookies).
7. **Tests + adversarial scope pass** — a capture key is rejected on `/api/projects`, `/api/conversations`, `/api/account`, etc.; accepted only on the ingest endpoint; endpoint allowlists + scrubs; feature-detection (no scope column → 'full').

## Decisions / notes

- Browser captures → deterministic **per-host project** (named after the host) for the MVP. AI semantic grouping of browser chats is a documented follow-up, not Slice A.
- Re-uses the daemon's allowlist+scrub contract so daemon and direct-to-backend ingest behave identically.
