From mcp/src/capture/cli.ts:316-357 (`restartDaemon` + `waitForProcessExit`):
The race guard the Layer 9 E2E tests: `restartDaemon` polls `process.kill(oldPid, 0)` until ESRCH (with a 5s ceiling + SIGKILL escalation), THEN spawns the new daemon. The E2E exercises this by calling enable/disable 3× rapidly in a row and asserting no EADDRINUSE in the daemon log AND that port 7727 is in the correct state after each call.

Cline + Roo Code + Copilot CLI all derive the session id from the PARENT DIR name (not the file name).
